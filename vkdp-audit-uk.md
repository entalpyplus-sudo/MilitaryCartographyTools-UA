# Перевірка Military Cartography Tools — 15.11.2026

Перевірено українське доповнення встановленого плагіна та його взаємодію зі звичайними формами й інструментами QGIS 4.2.3. Нормативна звірка стосується наданої редакції ВКДП 5(3)-00(01).02, затвердженої наказом №140 від 11.09.2020: файл `Порядок-оформлення-БР.pdf`. Номери сторінок нижче — надруковані в документі; у файлі PDF до них додаються дві сторінки.

## Виправлено

| Проблема | Результат |
|---|---|
| Залежні поля були постійно доступні | Штатні правила форм QGIS вимикають їх до вибору батьківського параметра. Враховуються також умови батьків наступного рівня. Значення не стираються. |
| Вибір у PNG-пошуку міг випереджати стан решти форми | Перегляд і доступність полів читають поточний вибір редактора. Очищення PNG повертає вибір на векторний знак через звичайний редактор QGIS. |
| У новому українському режимі було лише чотири варіанти належності | Для обрамлених знаків доступні всі сім варіантів; їх також додано до українського вставлення в макет. Форми та заливки перевірено за розділом 5.2 і таблицею 6, с. 68–71. |
| Синій знак питання був чорним у нових шарах | Знак неперевіреної інформації синій; у чорно-білому режимі — чорний (пп. 2.2.15 і 2.2.13, с. 26–27). |
| Нейтральні заходи управління мали різні кольори в точках та лініях | Для їхнього нанесення узгоджено коричневий колір за п. 2.2.5, с. 25. Нейтральне заповнення обрамлених електронних знаків залишається зеленим за таблицею 6. |
| Загородження противника успадковували зелений колір класичного режиму | В українських шарах свої загородження зелені, противника — червоні; чорний варіант доступний окремо (пп. 2.2.4, 2.2.6, 2.2.13). |
| Частина пояснювальних підписів залежала від кольору належності | Звичайні підписи QGIS та текст у точкових знаках заходів управління приведено до чорного кольору (п. 2.2.3, с. 24). |
| Порожній або невідомий код стану ураження міг утворювати перекреслення | Перекреслення наноситься лише для трьох визначених станів. Перевірено два суцільні, суцільний і штриховий та два штрихові відрізки за п. 2.2.12, с. 26. |
| Посилення / послаблення F можна було наносити на невідповідний рівень | Поле доступне для визначеного рівня від групи до дивізії; на вищих рівнях його збережене значення не малюється (п. 5.4.8, с. 80–81). |
| Шаблон морської піхоти починався із загального десантного знака | Використовується амфібійна піхота 121101 з військово-морським модифікатором. Загальний амфібійний знак залишено окремим типом. Український шаблон використовує редакцію D незалежно від останнього вибору редакції НАТО. Орієнтир — приклад на с. 177. |
| Адаптація стилю перетворювала порожні пункти ValueMap на NULL | Під час зміни оформлення зберігаються початкові налаштування редакторів і форми, включно з пунктами «Немає» та відсутністю ешелону. |
| Один JavaScript-рушій міг використовуватися різними потоками малювання | Кожен потік отримує власний рушій; це перевірено окремим тестом на кількох потоках. |

## Залежності полів

- Штаб → напис КП/КСП та інших пунктів управління.
- Стан ураження з перекресленням → сторона, засобами якої завдано ураження; у чорно-білому вигляді вибір кольору недоступний.
- Власний PNG → його розмір. Параметри побудови векторного знака стають недоступними, поворот залишається доступним.
- Тип знака → модифікатори, ешелон і штаб, якщо ці поля є у відповідному шарі.
- Визначений ешелон до дивізії включно → посилення / послаблення F.
- Група морських знаків або сфера у старому універсальному шарі → відфільтрований список типів.
- Розмежувальна лінія → ешелон і позначення суміжного підрозділу.
- Бойова позиція → ознака підготовленої позиції.
- Багатокласовий пункт постачання → вибір класів постачання.
- Колона → тип техніки, додаткова інформація та дати/час колони.
- Відповідний тип замінованого району → параметри мін; відповідна зона загороджень → її часові параметри.
- Додатна дальність кільця → лівий/правий азимут і висота/глибина цього кільця.

Вимкнення батьківського параметра не видаляє попередньо введені дочірні значення. Вони знову доступні після виконання умови. Користувацькі умови редагування й режим лише читання зберігаються.

## Перевірено окремо

- Створення всіх 26 категорій / 55 схем шарів зі звичними меню, геометрією та формами.
- Малювання всіх 1287 доступних варіантів типів із типовими параметрами; цей тест виявляє технічні помилки малювання, а не доводить нормативну тотожність кожного зображення.
- Залежні поля до і після зміни параметрів; збереження неактивних значень; скасування форми; вибір та очищення PNG.
- Звичайне збереження в GeoPackage, збереження проєкту та його повторне відкриття.
- Точка прив’язки пункту управління, довгі підписи, кольори, перекреслення, сім варіантів належності та шаблон морської піхоти.
- Вихідний діалог вставлення знаків у макет для обох систем, окрема бібліотека PNG та вивантаження плагіна.
- Усі 1055 PNG перевіряються за SHA-256 під час встановлення; оригінальні зображення не редагуються.

Журнали: `classic_ui_test.log`, `audit_test.log`, `audit_labels.log`; результат перебору типів — `audit_render.json`. Звіт про встановлення, список змінених файлів і шлях резервної копії — `audit_install.json`.

## Межі перевірки

Це перевірка реалізованих функцій та перелічених правил оформлення. Повну графічну звірку кожної піктограми, усіх поєднань модифікаторів і всіх спеціальних прикладів 267-сторінкового документа не виконано. Каталог плагіна також містить успадковані типи MIL-STD/APP-6; назва режиму ВКДП сама по собі не підтверджує нормативність кожного такого типу.

Не всі додаткові ампліфікатори документа, зокрема окремі індикатори мобільності та боєздатності, мають власні поля у вихідному плагіні. Додаткові умовні позначення потребують пояснення в легенді відповідно до п. 2.2.16. Власний PNG залишається готовим зображенням: він не перебудовує вміст за зміною векторних параметрів.

Знак X з літерою D у каталозі тактичних завдань «Знищити» збережено й перевірено за прикладом «Знищення» на с. 135. Він не додається автоматично до знака підрозділу зі станом ураження «Знищено»; для такого стану застосовується перекреслення за п. 2.2.12.
